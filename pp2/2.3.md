# Step 2.3: WebSocket Live Logging (Code Implementation)

## Overview
Connect FastAPI WebSockets to Redis to push the Celery training state to the UI.

## 1. WebSocket Route (`app/api/routes/training.py`)
```python
from fastapi import APIRouter, WebSocket, WebSocketDisconnect
from celery.result import AsyncResult
import asyncio
import json

router = APIRouter()

@router.websocket("/ws/{task_id}")
async def websocket_training_endpoint(websocket: WebSocket, task_id: str):
    await websocket.accept()
    try:
        while True:
            task = AsyncResult(task_id)
            if task.state == 'TRAINING':
                await websocket.send_json(task.info)
            elif task.state == 'SUCCESS':
                await websocket.send_json({"status": "SUCCESS", "result": task.result})
                break
            elif task.state == 'FAILURE':
                await websocket.send_json({"status": "FAILED"})
                break
            await asyncio.sleep(1) # Poll every second
    except WebSocketDisconnect:
        print("Client disconnected")
```
