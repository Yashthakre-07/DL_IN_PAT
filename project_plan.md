# 🌐 PAT-IQA Web Platform: Project Plan

## 📝 Project Overview
The goal of this project is to transition the **Photoacoustic Image Quality Assessment (PAT-IQA)** research into a fully functional, premium web application. The platform will serve as a comprehensive suite for researchers to evaluate, train, and diagnose photoacoustic image quality without needing to interact with raw code.

---

## 🛠️ Core Functional Modules

### 🧪 Module 1: Analytical Comparator (Traditional IQA)
*   **Feature:** Allows users to perform mathematical ground-truth comparisons between two images.
*   **Capabilities:**
    *   **Upload Interface:** Side-by-side uploader for "Test Image" and "Reference Image."
    *   **Metric Suite:** Real-time calculation of 14+ metrics (PSNR, SSIM, VIF, FSIM, MSSSIM, etc.).
    *   **Visual Diff:** Overlay tool to see pixel-wise differences between images.

### 🧠 Module 2: AI Training Studio (Deep Learning)
*   **Feature:** A user-friendly interface to train custom quality assessment models on local datasets.
*   **Capabilities:**
    *   **Dataset Management:** Bulk upload of images and CSV labels.
    *   **Model Selection:** Dropdown to choose architectures (PAQNet, PhotoacousticQualityNetBN, EfficientNet-B0 Multi, etc.).
    *   **Training Configuration:** Adjustable epochs, learning rates, and data split ratios (e.g., 70/15/15).
    *   **Multi-Metric Optimization:** Option to train models that predict all metrics simultaneously.
    *   **Model Vault:** Save trained `.pth` weights to a local repository for later use.

### 🔍 Module 3: Neural Diagnostics (Inference & Interpretability)
*   **Feature:** Deployment of trained models to assess new images and visualize AI "reasoning."
*   **Capabilities:**
    *   **Rapid Inference:** Instant prediction of quality scores for a single uploaded image.
    *   **Diagnostic Heatmaps (Grad-CAM):** Visual overlay showing which parts of the image (streaks, blur, noise) influenced the AI's score.
    *   **Comparison Mode:** Compare predictions from different models (e.g., PAQNet vs. EfficientNet) on the same image.

## 💻 Technology Stack

| Layer | Technology | Rationale |
| :--- | :--- | :--- |
| **Frontend** | **Next.js + Tailwind CSS** | For a premium, reactive, and responsive "Light Mode" dashboard. |
| **Backend** | **FastAPI (Python)** | High-performance asynchronous API for ML inference and training. |
| **AI Engine** | **PyTorch** | Leverages the existing PAQNet and metric logic. |
| **Charts/Graphs** | **Recharts / Chart.js** | Live visualization of loss curves and metric distributions. |
| **Processing** | **Celery + Redis** | To handle long-running model training in the background. |
